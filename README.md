# Don Chat

Real-time messaging application with AI assistant powered by Parse Server (Back4App).

## Features

- 🔐 User Authentication (Register/Login)
- 💬 Real-time Messaging
- 🤖 AI Assistant (Don AI)
- 🌙 Dark/Light Theme
- 📱 Responsive Design
- 🗑️ Message Actions (Edit, Delete, Clear All)
- 👥 User Directory

## Tech Stack

- **Frontend**: Next.js 16, React 19, Tailwind CSS 4, shadcn/ui
- **Backend**: Parse Server (Back4App)
- **Real-time**: Socket.io
- **AI**: z-ai-web-dev-sdk

## Getting Started

1. Clone the repository
2. Install dependencies: `bun install`
3. Set up environment variables
4. Run: `bun run dev`

## Environment Variables

```
PARSE_APP_ID=your_app_id
PARSE_JAVASCRIPT_KEY=your_javascript_key
PARSE_SERVER_URL=https://parseapi.back4app.com
```
